`/client_groups` endpoint isn't returning datapoints for each subgroup.
Datapoint `value` attribute stores raw DynamoDB values in a collection. 
```json
"value": [
	{"S": "Asthma"},
	{"S": "Diabetes"}
]
```

We want the deserialised versions of the same values
```json
"value": [
	"Asthma", 
	"Diabetes"
]
```
