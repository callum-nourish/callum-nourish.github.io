This card involves creating a new route for "Goals and Outcomes" within the application, which will be accessible only to users with the appropriate feature toggle enabled. The route will be nested under the client and will include a link in the client navbar. The term "Objectives" will be customisable at the organisational unit level, similar to the support network term.

- Add feature toggle for "Goals and Outcomes" in the admin panel
- Add a new route for Goals and outcomes at `/objectives`; this is nested under the client. This should only be accessible to users with the "Goals and Outcomes" feature toggle enabled.
- Add a link in the client navbar; when clicked this should go to the new route. This should be titled "Objectives" but this should be a customisable term at org unit level similar to support network term; This should only show if the feature toggle is enabled.

# Questions
- What symbol shall we use for the new link in the client navbar?
- How should the customisable term for "Objectives" be implemented in the org unit configuration - where is that term being sourced from?
