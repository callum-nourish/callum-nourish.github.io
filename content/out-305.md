# OUT-305: Update support network term in roles section to be dynamic

Follow-up to OUT-283 that implements dynamic support network terminology. An additional location was discovered in the admin roles section that needed to display the dynamic term instead of hardcoded "Circle of Care".

## Problem
The admin roles section in `/app/views/admin/people/circle_of_care.html.erb` contains hardcoded "Circle of Care" references that should use the dynamic support network term from organisation settings.

## Solution
Update three locations in the view file:
- Line 1: Dynamic term retrieval from organisation settings
- Line 32: Submit button text 
- Line 45: Help text reference

## Files Affected
- `app/views/admin/people/circle_of_care.html.erb`
