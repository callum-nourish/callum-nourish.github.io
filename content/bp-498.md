Users were resetting their passwords via AWS admins who resetted passwords for the user.

We need a password reset page (wrapper for cognito password reset) so users can reset their passwords for their AWS Cognito accounts (required credentials to access Nourish Studio). Thus enabling access to things like libraries / data points.

# Card Checklist
- [x] Outline requirements to the AI to create the changes
- [x] Password reset page
- [x] Integration to AWS cognito sending the user email a 6 digit code (expires after 24 hours)
- [x] ~~[-] Format verification code email to represent the true purpose of the email~~

# Decisions
2026-02-26

- Added frontend cooldown timer to prevent spam emails of verification codes
- Created custom Nourish Studio password reset page instead of using native AWS password page; providing a nicer user experience
- Documentation for the feature
