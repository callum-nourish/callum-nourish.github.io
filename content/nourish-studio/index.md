Vue and Vite app for configuring care interactions. Operators use Studio to build the interaction templates that [[Better Care]] surfaces to carers.

[nourish-form-ui](https://github.com/nourishcare/nourish-form-ui) · Vue · Vite

[[Pulse]] is the shared component library consumed by both Studio and [[Better Care]].

## Current Work

[[Packaging ParameterList for Nourish Studio]] — shipping a render-only `ParameterList` package from `nourish-organisations` so Studio can preview interaction parameters without owning the renderer.
