# OUT-399
We are currently only displaying a label with the status of Milestones, which can be confusing. For consistency, we should also display this for goals the status for goals in list and side panel
!
- Add status label to each goal on the list view (colours and statuses as previously implemented for milestones)
- Goal status **does not show** on edit goal or archive goal side panel view
- Add status label to each goal on the side panel view

**Acceptance criteria**
- The correct goal status displays for each goal in both the goals list view and side panel views
- Goal status does not show on edit goal or archive goal side panel view
- Milestones status also display as expected in both goals list and side panel views (could be a redundant point here)
