# Aim
To resolve N+1 query and have number of queries grow with the quantity of data
# Initial
The client_groups endpoint currently 
1. Loads root level group objects; **1 query** 
2. Load subgroups, datapoints and subgroups datapoints in dictionary **N Queries**
```
For each group
1. Get children items (subgroups/datapoints) **calls up to 9 queries**
2. For each item **up to N queries**
	1. If item is group, **query datapoints for this group**
```
3. Load values for all datapoints in dictionary **1 query**
4. Using all collected data, build response into predefined shape.
