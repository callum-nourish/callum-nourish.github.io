Given a date range, we want the exported care plan report to list the versions of a need and interactions within that time frame.
### Plan

	- Previous Reviews
	- Linked Interactions
	- Interaction logs
- Since this report is being generated in the backend by sidekiq as a job
	- We iterate through each "field"'s version / object and list them from newest to oldest in the report (careplan_subcategory) list_interactions

As an Admin, I want to be able to run a report across a time period to see changes to Care Plans through time.

Regulators often want to see evidencing of improvement/learnings over a sustained period of time and the restriction of only being able to run a care plan report for the current version is making this difficult for providers.

**Impact:**
Evidencing learnings in care plan alterations is currently not possible, meaning this can not be used as evidence during inspections.

**Proposed Solution:**
Add a date selector to the care plan report to allow users to select a time period and see the care plan history between the dates.

**Acceptance Criteria:**
- Date selector component appears on the Care Plan report as per linked designs
- Report Output is updated when more than one day is selected for the reporting period
    - [x] Saved versions of the Care Plan history should be returned within the date range selected
    - [ ] Versions of care plan folders and/or pages should be displayed in date order from oldest to newest
	    
    - Care Plan folders and/or pages should display once on the report output, **unless** changes have been made to the input fields within the date range selected.
    - If ‘Interaction Logs’ is selected, then the latest completed interaction log should be displayed in the output closest to the date range of the care plan version it relates to. This should be done for each version history. (Please see example output)
    - If ‘Linked interactions’ are selected then Interactions linked to the section of the care plan should be displayed. Title should be updated to read “Linked Interactions”.
    - If ‘Previous reviews’ are selected, then these should be included as per the current functionality (whether a single date or a date range has been selected). If a date range has been selected, the review for each version history should be displayed.
        

**Examples**

Care plan report run for a date range of 13 months

Care Plan Version History examples:

- Care plan Page Title or Description update. _Care plan **page** versions are only displayed once in the output, unless the title or description is updated._
    
- Care plan Need updates. _Care Plan **need** versions are displayed in date order from oldest to newest under the page title._
    
- Linked interactions update. _**Interactions** in care plan will now be called **Linked Interactions**, this change is for consistency and clarity. They will only be repeated if they change. if there are no version history changes, only display them once same as page title/descriptions._
    
- Interaction logs update. _The Latest Interactions logged for each version history up to that date will be displayed, eg. Careplan need updated 01/01/2022 closest logged Interaction is 12/12/2021, next version history is 02/03/2022 closest logged interaction is 24/02/2022._
