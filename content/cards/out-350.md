!
Enable users to view all images attached to the “Update milestone” interactions that are linked to the milestone in a clear, visually organised gallery under the **Activity Log** section of the milestone. 

This will enable uses to easily visualise their progress in an accessible way via media. We will be utilising the Pulse Component `PulseGallery` for this. 

**Requirements**
- [ ] Add new endpoint (in the backend) to get images from the interactions linked to the milestone to display in the PulseGallery.
- [ ] Add pulse component created in OUT-440 under the Activity Log within the milestone drawer
- [ ] Add header “Photo Journey” for and above the PhotoGallery under the Activity Log
- [ ] Display number of images linked to the milestone in brackets next to the Photo Journey header (total images across all interactions).
- [ ] When no images are yet available on liked interactions to display - show section headers as Photo Journey (0).
- [ ] **Display all images attached to the interaction type (Service model) “Update milestone” interactions linked to a milestone.**
- [ ] **For the initial release, include only the “Update Milestone” interaction types (each interaction currently supports only one image to be uploaded).**
- [ ] **Interaction details displayed beneath the image as displayed in the activity log:**
    - [ ] **Milestone name**
    - [ ] **Date closed**
    - [ ] **Closed by**
    - [ ] **Description**
- [ ] **Clicking outside the modal should close it**

**Acceptance Criteria**
- The milestone detail view displays a Photo Journey section under the Activity Log.
- The section only displays if at least one image is added to the interactions linked.
- Gallery shows all images attached to “Update Milestone” interactions only.
- Gallery layout shows up to 9 thumbnails per page in 3 rows, with pagination appearing when there are more than 9 images.
- Clicking an image opens a modal with:
    - The image displayed in a centered square card format.
    - The image adjusts within the square modal depending on the image display (landscape, portrait,etc) as per designs.
    - Details below the image: Interaction name, Date closed, Closed by, Description.
    - Navigation arrows to move between images.
- UI behaviour and styling match the latest Pulse designs for gallery and modal components.
- The feature should gracefully handle cases where:
    - No images are available (gallery section hidden or displays “No images yet”).
    - Images fail to load (placeholder or error state shown).
