We should be able to
1. See the legal name, I.e. "John Smith" when editing datapoints
2. See prefilled values for name and description for groups and datapoints
3. Be able to move datapoints freely. 
	1. Main list -> Group
	2. Main list -> Subgroup
	3. Group -> Main list
	4. Group -> Subgroup
	5. Subgroup -> Main list
	6. Subgroup -> Group
# Initial State
The user's email shows after they edit a datapoint. There are no prefilled values. I get an Internal error 500 when attempting to move a datapoint from a group to the main list.
