A filter in the goals page allowing the user to view Goals by **status**. 
The default view should be “In progress”; if none, fall back to “All Goals”. 
Preserve filter state across navigation.
**Filter Options to Implement**:
- All Goals
- Not Started; If start date is in the future
- In Progress; today's date is more than or equal to start date and less than complete date.
- Completed; completed_at column has a value.
- Archived; archived column is true
