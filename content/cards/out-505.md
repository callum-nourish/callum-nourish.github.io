This ticket introduces a new Critical Information section within the Administration area of Nourish (web), enabling authorised users to access and manage Critical Information settings at the Organisation Unit level.

- Add Critical Information section to "Administration" panel
	- positioned below “Care type” within Organisation Unit settings.
- Only users with "permission" within org unit can access this section; FT must be enabled [[OUT-508]]
	- "Manage Critical Information Configuration" permission
- This section added to existing settings under "Device Management"

### Background / Context
To enable the functionality to be able to customise the information displayed in the critical information dashboard for a PWS at the org unit level. 
We need to add a section in the “Administration” section of the left hand panel in Nourish (web) called “Critical Information” that users with the permissions to edit critical information for a given org unit can access to adjust these settings. 
This section should be added at the bottom of the existing settings under “Device Management”

**Requirements**
- This section will contain the settings functionality to adjust critical information settings for the relevant org unit
    
- Visibility and access to the Critical Information administration section must be governed by the existing “Manage Critical Information Configuration” permission. [https://nourishcare.atlassian.net/browse/OUT-490](https://nourishcare.atlassian.net/browse/OUT-490)
    
- A new Critical Information section should be added to the Administration left-hand navigation in Nourish (web), positioned below “Care type” within Organisation Unit settings.
    
- This section should create a new empty page where we will add the settings functionality to customise critical information.
    
- This work should be under the FT custom_critical_information created on [https://nourishcare.atlassian.net/browse/OUT-508](https://nourishcare.atlassian.net/browse/OUT-508)
    

### Problem
As an Admin user, or a user with permission to manage Critical Information, when configuring my Organisation Unit, I want to be able to clearly see and access a dedicated Critical Information section within the Administration area of Nourish, so I can easily manage these settings in one consistent location.

### Acceptance Criteria / Definition of Done
- A new **Critical Information** section exists in the Administration area of Nourish (web)
- The section appears in the left-hand navigation under Organisation Unit settings, positioned below Device Management
- The section is:
    - Visible and accessible only to users with the relevant permission
    - Hidden from users without permission
- Clicking the Critical Information section opens an empty screen that will contain the Critical Information configuration screen for the selected Organisation Unit (to follow in future tickets).
- The section respects Organisation Unit context (settings apply only to the selected unit)
- The Critical Information section is preceded by the relevant icon as per designs
- Work is under the FT custom_critical_information
