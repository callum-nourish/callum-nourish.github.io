Nourish Studio can display and navigate grouped datapoints using a stable API contract (`groups` + `dataPoints`) that supports current UI acceptance criteria.

# Initial
- Existing datapoints endpoint returns a flat shape (`codename`, `description`) that does not match UI requirements.
- UI requires grouped response structure with parent relationships.
- This ticket includes read/navigation behavior; actions menu and search are out of scope.
- Recent sync indicates UI and endpoint work are in progress but contract naming/shape is still uncertain.
