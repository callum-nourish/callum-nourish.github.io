This is for front end only. [[OUT-363]]

Add a “Goals” icon to interaction that triggers a dropdown list of milestones to select form in order to link an interaction to a milestone

As a user, I want to be able to link any interaction belonging to a client to a milestone (and the corresponding goal) that they are working on, so I can track their progress towards them.

### Requirements
- [x] Add an icon `PulseIcon` to the vue component “Quick Actions” with a label of “Link to Milestone” `vue/src/timeline/components/QuickActions.vue`
- [x] When clicking this icon, it should then show a component underneath the actions to link a milestone. ✅ 2025-09-19
	- [x] **Create Dropdown Pulse component** based on [Vue TreeSelect Component](https://primevue.org/treeselect/) ✅ 2025-09-23
	- children property to add milestones ? ^qQ3Xyf7o
- [x] Only goals and milestones that are In progress should be displayed in the dropdown ✅ 2025-09-24
- [x] Each milestone should be displayed underneath its relevant goal as displayed in the designs ✅ 2025-09-24
	- [x] The dropdown list will show all milestones for each goal available for that client ✅ 2025-09-24
		- [ ] **All Milestones? Even completed/archived?**
		- [ ] **Just "in progress" - what about not started (an active milestone).**
- [ ] When selecting a milestone, it should save this to the currentInteraction as “milestone”. This will need to be added to the IInteraction type so it knows what a milestone is. `vue/src/timeline/store/currentInteractionStore.ts`
- [ ] Each interaction should only be linked to one milestone at a time (in the future we may add more) `if there is no interaction.milestone then add milestone`
	- **therefore keep it scalable to accept a collection?**; yes

**Acceptance criteria**
- [x] The “Link to Milestone” icon is visible and functions as intended. ✅ 2025-09-24

- [x] Dropdown correctly lists all goals and their corresponding milestones ✅ 2025-09-24
	- **Any particular order? Latest first?** - yeah
- [x] Only goals and milestones that are In progress should be displayed on dropdown ✅ 2025-09-24
	- Goals and milestones in the status: Not started, Completed or Archived should not be displayed in the dropdown
- [ ] Selected milestone gets saved to the currentInteraction.

	- Api endpoint by id; **seems the most straightforward since the interaction itself can hold a collection of the ids. To get the titled for all the milestones, we just query an endpoint for the id**

	- The in progress collection?
		- What if the milestone itself is completed and a carer wants to see that selected milestone; it's no longer in the in progress list.
